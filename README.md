# لعبة العائلة — V6

نسخة V6 جاهزة للنشر، مبنية على Socket.IO + Express + PostgreSQL.

## إضافات V6
- تصميم تلفزيوني كامل لشاشة العرض.
- شاشة مقدم محسنة مع بنك أسئلة.
- شاشة متسابق مناسبة للجوال مع زر ضغط كبير.
- مؤثرات صوتية WebAudio بدون ملفات صوتية خارجية.
- حركات ظهور الإجابات، وميض المؤقت، شاشة فوز.
- QR Code للانضمام للغرفة.
- رابط الانضمام `/?join=CODE`.
- حفظ الغرف والأسئلة في PostgreSQL.
- PIN للمقدم وإعادة الدخول للغرفة.
- 3 Strikes، النقاط، الجولات والمؤقت.
- Docker وRender جاهزان.

## التشغيل المحلي
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## Render
أنشئ PostgreSQL وأضف `DATABASE_URL` إلى خدمة الويب. استخدم Build Command:
`npm install`
و Start Command:
`npm start`

## ملاحظة
الأصوات مولدة من المتصفح. قد يطلب المتصفح أول نقرة من المستخدم قبل تشغيل الصوت، وهذا سلوك أمان طبيعي للمتصفحات.
