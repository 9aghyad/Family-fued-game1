# Family Feud Realtime V7

## ما تم تغييره
- إزالة مؤقت الجولة بالكامل من الخادم والواجهات.
- فصل الروابط إلى:
  - `/host` صفحة المقدم.
  - `/display` شاشة العرض للتلفزيون.
  - `/player` صفحة المتسابقين.
- صفحة المقدم تتطلب PIN عند إعادة الدخول، ورمز الغرفة وحده لا يمنح صلاحيات المقدم.
- شاشة العرض مصممة أساسًا للوضع الأفقي 16:9 مع إجابات كبيرة وواجهة أقرب لبرنامج تلفزيوني.
- إضافة زر **السؤال التالي** للمقدم للانتقال مباشرة إلى السؤال التالي من بنك الأسئلة.
- بنك الأسئلة الافتراضي أصبح 51 سؤالًا عربيًا مع إجابات ونقاط، مع إمكانية إضافة المزيد.
- QR أصبح يفتح صفحة المتسابقين مباشرة.

## التشغيل
```bash
npm install
npm start
```

في Render استخدم أمر التشغيل `npm start`.
